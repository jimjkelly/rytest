# Jest Research

We create a simple project here so we can test with Jest to see what
we like and dislike about Jest.

## Run

You can run these tests either via `npm test` or `npm test-watch` to enable
watch mode.

## The Good

Decent UI out of the box.  Clear PASS/FAIL messaging.  Watch mode is
very cool and quite useful.

## The Bad

Unclear if "only run tests related to changed files" actually works?
